# BackupBuddy 🛡️
> *“Plan today, recover in minutes.”*

## About Our Startup
BackupBuddy is a specialized service designed for small businesses and local organisations (such as small clinics and local shops) that do not have a dedicated IT team. Our main purpose is to help teams build reliable backup habits and practise recovering sample files in a safe environment.

## Team Roles & Responsibilities
* **Cybersecurity Analyst:** Creates secure backup rules, manages data protection policies, and designs realistic file-recovery scenarios.
* **Customer Support Specialist:** Guides users through backup setups, conducts practice recovery sessions, and helps clients during emergencies.

## Key Features
1. **Personalised Backup Planner:** Automatic weekly reminders for data safety.
2. **Safe Training Simulator:** Practise recovering sample files without risking real business documents.
3. **Step-by-Step Checklists:** Simple, clear instructions for non-technical staff.

## Technology Stack
* **Backend:** Python (for automation and simulation logic).
* **Platform:** Web-based service (accessible via any browser without installation).
* **AI Integration:** Smart assistant for scheduling recommendations and emergency guidance.
